# Gallery caption semantics — 2026-10-29 ~17:40 PHT

The migrated two-gallery viewer (three and seven existing images) already offers keyboard navigation, modal focus restoration, source alt text, and a polite position announcement. Its visible caption paragraph was not programmatically associated with the displayed image. This reader-facing accessibility improvement assigns a stable caption ID and applies `aria-describedby` to the modal image **only** when a distinct source figcaption exists. The existing visible alt fallback remains for captionless images without causing a duplicate screen-reader description. The association updates on Home/End and arrow navigation; the offline DOM runtime tests both association and removal when navigating to a captionless image.

Scope: only `public/assets/gallery-viewer.js`, `scripts/test-gallery-viewer.mjs`, and this operations note. No new images, copies, public article-body changes, PDF edits, WordPress writes, drafts, comments, source media bytes, noindex, or rights/public-launch changes. This is a semantic improvement, **not** manual screen-reader certification or original Newspack global-carousel parity. Preserve CHM-B040 safety restriction; never retry or bypass the rejected CS12 operation.

Acceptance requires exact-head CI including the mandatory gallery runtime test, independent review of the final branch diff, successful PR merge, and authenticated Vercel production READY at exact main.
