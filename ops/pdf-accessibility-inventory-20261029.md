# Public PDF accessibility and provenance gate (2026-10-29 ~11:33 PHT)

This is an **independent, read-only QA gate** for the three published PDFs already in the 82-asset migration manifest. It does not OCR, modify, annotate, tag, replace, redistribute or grant rights over any source. Original WordPress remains read-only; no private draft metadata, associations or images are included.

## Exact scope and acceptance

- Pin `pypdf==5.9.0` in a separate GitHub Actions workflow, after the existing complete build.
- Fail closed on changed PDF manifest identity, missing/escaped path, non-PDF signature, encrypted/unreadable PDF, zero-page PDF or changed aggregate nine-page baseline. The existing media-integrity and full-build checks separately verify generated bytes.
- Inventory page count, per-page extracted character count (fewer than 20 is flagged as effectively textless), `/StructTreeRoot` and `/Lang` indicators, and generated SHA256. Save JSON as a CI artifact. No page text or confidential contents are copied into the report.
- A text layer, `/StructTreeRoot` or language metadata is **not proof of accessibility**. The report explicitly requires manual accessibility review for every PDF, including any apparently tagged one. A missing text layer is not repaired by this change.
- This structural gate is additional to, and cannot replace, manual screen-reader and keyboard review, archival provenance and owner rights/attribution decisions. Three PDFs and nine pages were previously inventoried, with seven of nine pages textless by earlier methods; new extractor results must be treated as a separate measurement.
